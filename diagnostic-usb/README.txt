KP RTL8831BU 애드온 설치 실패 진단 USB

1. 이 ZIP의 내용물을 별도 USB의 최상위에 풉니다.
2. 차량을 정차한 상태에서 USB를 꽂고 NEMESIS 실행 확인창에서 승인합니다.
3. 진단 완료 표시 후 USB를 빼서 KP_AX_INSTALL_DIAG.txt를 전달합니다.

기존 설치 실패 기록을 읽으므로 애드온을 다시 설치할 필요가 없습니다.
별도 USB가 없다면 기존 설치용 NEMESIS.data를 먼저 USB 밖에 보관한 뒤
진단용 NEMESIS.data, NEMESIS.sh, KP180-stock.sha256를 USB 최상위에 두십시오.
차량 패키지와 설정은 읽기만 하며, 결과 파일은 USB에 기록합니다.
