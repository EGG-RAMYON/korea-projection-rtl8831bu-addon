# 1.0.0 · RTL8831BU 애드온 개발판

- 공식 Korea Projection v1.8.0 의존성을 가진 별도 NEMESIS 패키지입니다.
- ipTIME AX900mini B831용 RTL8851BU 계열 ARMv7 모듈, 대상 확인, 부팅 보호, 채널 36 / KR 프로필을 추가했습니다.
- 원본의 RTL88x2BU 모듈, 앱, Wireless 2.4.9를 그대로 사용합니다.
- AX AP에 IPv4·IPv6 전달 차단을 추가했습니다. 단말의 HU 로컬 통신은 기존 DHCP·AP 경로를 사용합니다.
- USB 설치·삭제용 ZIP, 소스, v1.8.0 서비스 diff, WSL2 빌드 자료, SHA-256을 함께 제공합니다.

실제 대상 차량을 이용한 설치 및 동작 검증이 남아 있습니다.
