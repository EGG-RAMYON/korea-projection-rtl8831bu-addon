# Korea Projection 1.8.0 RTL8831BU 애드온

korea.projection.rtl8831bu 1.0.2은 ipTIME AX900mini를 위한 비공식 개발판입니다. 먼저 **공식 Korea Projection v1.8.0**을 설치합니다. 애드온은 별도 NEMESIS ID를 사용하며 KP v1.8.0의 서비스와 파일 목록 두 개만 백업하고 교체합니다. KP APK, HMG-API 모드 ZIP, 두 기존 RTL88x2BU 모듈은 설치한 공식 패키지에서 사용합니다.

## 설치와 첫 검증

1. 차량을 정차하고 별도 승인을 받은 뒤 진행합니다. 조사한 NEMESIS 1.17 소스에는 정확한 버전 의존성과 서비스 중지 명령이 있습니다. NEMESIS Manager에 공식 KP가 있는지 확인합니다. 기존 베타·개발판이 설치돼 있으면 공식 v1.8.0으로 복귀한 뒤 진행합니다.
2. PC에서 sha256sum -c SHA256SUMS를 실행합니다. USB 설치 ZIP의 내용물을 FAT32 USB 루트에 풉니다. 루트에 NEMESIS.data가 있어야 합니다. packages/ 아래 ZIP은 그대로 둡니다.
3. USB를 내비에 꽂고 NEMESIS 설치를 승인합니다. 애드온 이름에 Unofficial이 표시됩니다.
4. 설치 USB를 빼고 AX900mini를 꽂은 상태로 내비를 재부팅합니다. KP 상태 화면에서 USB Wi-Fi 동글 사용이 꺼져 있으면 켜고 다시 재부팅합니다. 드라이버 계열을 바꿀 때는 쓸 동글을 꽂은 상태로 재부팅합니다.
5. KP의 **제보 파일 만들기**를 실행해 결과를 확보합니다. 선택된 모듈, 바인딩, AP, 주소 할당, 무선 AA, LTE 전달 차단 순으로 확인합니다. 처음에는 휴대전화 자체 모바일 데이터를 끄고 검사합니다.

| 확인 항목 | 기대 결과 |
|---|---|
| 모듈, 장치 | 8851bu가 Live, 0bda:b831 인터페이스가 rtl8851bu에 바인딩, wlan0 생성 |
| AP·DHCP | 채널 36, 20 MHz, KR. 단말에 192.168.43.x 주소 할당 |
| 무선 AA | 휴대전화 페어링 후 실제 AA 화면과 입력 확인. CarPlay는 별도로 확인 |
| LTE 전달 차단 | IPv4·IPv6 FORWARD 선두에서 wlan0 양방향을 KP_AX8831로 보내고 단일 DROP 규칙 적용. HU 로컬 통신 확인 |
| 복구 | 애드온 제거 후 공식 KP 해시와 기존 동글 확인 |

## 제거 및 복구

- Manager에서 **Korea Projection RTL8831BU Add-on (Unofficial)**만 제거합니다. 연결 모듈은 강제로 내리지 않습니다. KP의 안내에 따라 동글 사용을 끈 뒤 동글을 분리하고 내비를 재부팅합니다.
- Manager에서 제거 항목에 접근하기 어렵다면 복구 USB의 내용물을 USB 루트에 넣고 실행을 승인합니다. 복구 USB는 같은 NEMESIS 제거 명령을 실행합니다.
- 파일이 알려진 해시와 다르거나 필요한 백업이 없어 제거가 중단되면 동글을 뽑고 정상 부팅한 뒤 공식 v1.8.0을 재설치합니다. 두 파일이 공식본으로 돌아오면 애드온 제거를 재시도합니다. 전원이 두 파일의 교체 중 끊겨 무결성이 맞지 않는 경우 KP의 기존 검사가 AP 시작을 막습니다.
- 공식 KP를 업데이트하기 전에 애드온을 제거합니다. 동일 버전 재설치는 애드온을 비활성화할 수 있습니다. 공식본이 확인된 상태에서 애드온을 제거한 뒤 재설치할 수 있습니다.

실차에서 무선 AA를 확인한 판은 과거 베타 Hotfix 2입니다. 이 애드온의 실차 설치·제거, CD-ROM 전환, 재부팅·재삽입, 무선 AA·CarPlay, LTE 전달 차단은 별도 확인이 필요합니다.

1.0.1은 설치 단계와 결과를 애드온 디렉터리의 install-status.txt에 기록합니다. 설치에 실패하면 이 릴리스의 진단 USB로 해당 기록을 수집할 수 있습니다.

1.0.2는 NEMESIS 정지 이후 남아 있는 KP 핫스팟 셸을 확인해 종료를 요청하고, 남아 있으면 파일 교체를 중단합니다.
